JobMitra update v2  -  how to install (about 5 minutes)

1. Unzip this file. Open the unzipped "skillmatch" folder, select everything inside it
   (backend, frontend, docs, README.md, UPDATE_INSTRUCTIONS.txt) and copy it.
2. Paste into your project folder (the one that already contains backend and frontend)
   and click "Replace the files in the destination".
   Your database settings (config\settings.py) are NOT in this zip, so they stay as they are.
3. Backend terminal (the one that shows (venv)):
      cd backend
      py manage.py migrate          <- REQUIRED: adds the new fields/tables
      py manage.py seed_demo        <- optional: refreshes the demo jobs
      py manage.py runserver
4. Frontend terminal:   Ctrl+C, then   npm run dev
5. Browser: press Ctrl+F5.

Emails: with no setup they are PRINTED in the backend terminal (look for "Subject:").
To send real emails, open docs\EMAIL_AND_DEPLOY_SNIPPET.py, copy it to the very bottom of
backend\config\settings.py, and put your Gmail address in EMAIL_HOST_USER and your Gmail
"App password" in EMAIL_HOST_PASSWORD (inside the quotes). Restart the backend.

Going online: read docs\DEPLOYMENT.md.   For your report/viva: docs\MATCHING.md.
